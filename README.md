# 🤖 Jarvis AI Chatbot

### Gemini-Powered Personal AI Assistant
A Python-based AI chatbot that uses the Google Gemini API to understand user queries and generate intelligent, conversational responses through a simple and user-friendly interface.

## 🌐 Live Demo

[Try Jarvis AI Chatbot](https://jarvis-ai-gemini-powered-personal-assistant-5iojfguruuwtrbo3vn.streamlit.app/)

## ⚙️ Features
* AI-powered conversational responses
* Google Gemini API integration
* Natural language interaction
* Simple and clean user interface
* Secure API key management using environment variables

## 🛠️ Tech Stack
* Python
* Google Gemini API
* python-dotenv
* Git & GitHub

## 🔄 How It Works
```text
User Query
    ↓
Python Application
    ↓
Gemini API
    ↓
AI Response
    ↓
User Interface
```

The user enters a query, the application sends it to Gemini, and the generated response is displayed through the chatbot interface.

## 🚀 Setup
```bash
git clone git@github.com:kasturitalewar/Jarvis-AI-Gemini-Powered-Personal-Assistant.git
cd Jarvis-AI-Gemini-Powered-Personal-Assistant
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Create a `.env` file in the project folder:
```env
GEMINI_API_KEY=your_api_key_here
```

Run the application:
```bash
python main.py
```
> Never upload your `.env` file or API key to GitHub.
